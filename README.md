### Learning OpenGL - By Implementing Data Structures and Algorithms

I will learn OpenGL (Graphics API) by implementing visualization of Various Data Structures and Algorithms using C/C++


### Project setup 

Pre-requisites:
1. C++ Compiler 
2. CMake (version >=3.20)
3. vcpkg (package manager)

Update vcpkg ROOT_PATH on `run.sh` file according to your system. Open a `bash` shell and run `run.sh`
